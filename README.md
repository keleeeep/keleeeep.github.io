# Fredy Gunawan, personal site

One static page (`index.html`, inline CSS, no build step) with no images. Content comes from the resume and `03-professional/career/freelance-profiles.md` in the COG vault.

## Preview

`python3 -m http.server 8000`, then open http://localhost:8000.

## Deploy

Hosted on GitHub Pages from `main` (root) at https://keleeeep.github.io/. Every push to `main` deploys. `.nojekyll` makes Pages serve the files as they are.

The previous site (course pages, 2024) is kept in the tag `archive/course-site-2024`.
